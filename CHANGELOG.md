# LaTeX Palette Changelog

## 1.0.0 - 2026-10-22

- Search LaTeX symbols and templates with English descriptions, aliases, and typo tolerance.
- Browse rendered previews, related results, categories, favorites, and recent picks.
- Paste LaTeX with Enter, copy snippets, and inspect required packages.
- Support macOS and Windows with an offline catalog and bundled previews.
- Include 3,100 entries and a one-time local installation command.
